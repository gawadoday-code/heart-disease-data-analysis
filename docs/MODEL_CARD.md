# Model Card

## Model

An interpretable logistic-regression pipeline selected after comparison with a dummy baseline, random forest, and gradient boosting.

## Intended use

- Junior data analytics portfolio
- Educational model evaluation
- Demonstration of leakage-safe preprocessing and cross-validation

## Not intended for

- Diagnosis
- Treatment selection
- Clinical triage
- Individual risk communication

## Inputs

`age`, `trestbps`, `chol`, `thalch`, `oldpeak`, `sex`, `cp`, `fbs`, `restecg`, `exang`, and `slope`.

Excluded:

- `id`: identifier
- `num`: direct source of the target
- `disease_present`: target
- `dataset`: retained for stratification and transportability testing, not prediction
- `ca` and `thal`: excluded from the primary model because of extensive missingness
- cleaning and validation metadata

## Evaluation

Current metrics are generated by `src/train_model.py` and saved to:

- `models/modeling_summary.json`
- `reports/model_comparison.csv`
- `reports/leave_one_dataset_out.csv`

## Main risk

Internal validation is stronger than performance on unseen hospitals. This suggests case-mix differences and limited transportability.

## Deployment status

**Not approved for clinical deployment.**

Prospective external validation, subgroup evaluation, calibration analysis, and clinically justified threshold selection would be required first.
