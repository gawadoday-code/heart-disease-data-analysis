# Pre-Publication Review Checklist

- [x] Raw dataset included and unchanged
- [x] Processed dataset reproduced by code
- [x] README structure matches the actual repository
- [x] Dashboard image link tested
- [x] Model scores generated by code, not typed manually
- [x] Dummy, logistic regression, random forest, and gradient boosting compared
- [x] Leave-one-dataset-out validation included
- [x] Data leakage variables excluded
- [x] Limitations and prohibited clinical use documented
- [x] Repository validation script passes

## Personal review before an interview

The project owner should be able to explain:

1. Why zero cholesterol values were treated as missing.
2. Why incomplete rows were retained.
3. Why `dataset` was used for validation but excluded from predictors.
4. Why logistic regression was selected despite similar complex-model performance.
5. Why internal validation does not guarantee performance at a new hospital.
