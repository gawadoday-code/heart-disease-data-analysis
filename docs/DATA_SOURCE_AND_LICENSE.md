- **Dataset:** Heart Disease
- **Repository:** UCI Machine Learning Repository

- **DOI:** https://doi.org/10.24432/C52P4X
- **Source page:** https://archive.ics.uci.edu/dataset/45/heart%2Bdisease
- **Dataset license:** Creative Commons Attribution 4.0 International (CC BY 4.0)

Suggested citation:

> Janosi, A., Steinbrunn, W., Pfisterer, M., & Detrano, R. (1989). Heart Disease [Dataset]. UCI Machine Learning Repository. https://doi.org/10.24432/C52P4X.

The four source labels used in this project are Cleveland, Hungary, Switzerland, and VA Long Beach. The dataset license applies to the data; it should not be confused with a license for the project code.
